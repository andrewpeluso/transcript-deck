How to build a YouTube knowledge base for your AI agent.

Save transcripts from videos you trust as Markdown files, connect them with an index, and point your AI agent at the folder. Ask it to cite the exact moments behind its answers.

Start with a topic and a question

I wanted to get better at naming YouTube videos, so I started saving advice from creators and strategists I trust. When I’m stuck, I can ask my agent what the sources say about the title I’m considering.

My library now covers hooks, thumbnails, and intros too. It includes Paddy Galloway on titles and thumbnails, and Aprilynne Alter’s videos on making a thumbnail and writing an intro. When I find a channel I want to learn from, I start with the videos that answer questions I’m working on.

Save one transcript per video

Make a folder for the topic. Use the Transcript Deck skill in Codex or Claude Code with the first video URL, then ask your agent to save the resulting Markdown in that folder. Repeat for each video you want to add.

Keep the video title, creator, original URL, and publication date when available. Keep the timestamp links too. Those are what let you check the creator’s exact wording later.

Give your agent an index

Use an index.md file to link to each transcript with a short description of what it covers. Ask the agent to read the index first, then open the files relevant to your question.

When you add a new transcript, update the index with its date and topic. YouTube changes over time, so I keep earlier sources and ask my agent to show where newer videos add to or disagree with them.

Ask a question with sources

Open the folder in your agent and give it a question. Ask it to link to the video and timestamp for each recommendation and say when the library doesn’t cover something.

Read index.md, then open the transcripts relevant to my question. Cite the original video and timestamp for each recommendation. If sources disagree, tell me where. If the library doesn’t answer my question, say so. Here’s what I’m working on: [describe your project or paste your question].
