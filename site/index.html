Setup details and optional install

The starter prompt works in a local macOS or Linux workspace with shell and network access. Your agent may ask permission to download its tools the first time.

For repeat use, install the skill with the Skills CLI.

npx skills add andrewpeluso/transcript-deck --skill yt-structure

Why clean up a transcript?

I built Transcript Deck for the same reason a chef washes, chops, and measures ingredients before service. I prepare the transcript up front so my agent can focus on applying the advice when I actually need it.

The headings help my agent find the passage it needs. The timestamp links let me check that it understood the advice in context.

Build a library your agent can reuse

I save transcripts on YouTube titles, hooks, thumbnails, and intros. When I’m working on a title, I can ask my agent to find the relevant advice across several videos, compare what creators say, and show me the moments behind its recommendation.

Each video gives it another source to draw from. The transcripts I’ve already prepared are ready for the next question, too.

How I used it to tackle my inbox

Andrew Peluso, creator of Transcript Deck

When my inbox got cluttered, I found a few YouTube videos about managing email. I turned them into transcripts and gave those to my agent to help me decide what to change.

We started with Tiago Forte’s approach. The plan was to unsubscribe first, then filter the messages I still wanted to keep. I saved Michael Mostert’s follow-up labels as an option if I was losing track of messages that needed a response.

I felt more confident in the plan because I knew whose advice it drew from and could go back to the source.

What to know before you start

Which AI agents can use Transcript Deck?
The skill is free to use with Codex or Claude Code in a local workspace on macOS or Linux. Your agent needs access to a terminal and the internet.
What does the Markdown file include?
A transcript grouped under topic headings, with links to timestamps in the original video. You can read it, give it to your agent, or save it in a knowledge base.
Do I need to install anything first?
Start by pasting the prompt into your agent. It checks for the tools it needs and sets them up if they’re missing. It may ask permission to download them.
What if the video has no accessible English captions?
Give your agent a subtitle file or paste a transcript. Transcript Deck retrieves existing captions and can structure text you provide. It needs one of those text sources to work.
