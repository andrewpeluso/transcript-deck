Try it on a video.

You’ll need your agent, Node.js 22.20+, and an up-to-date yt-dlp. Supports macOS and Linux.

Install yt-dlp

On macOS, run brew install yt-dlp. On Linux, run pipx install "yt-dlp[default]". Update an existing install if YouTube retrieval fails.

Your agent

Run in your terminal

npx skills add andrewpeluso/transcript-deck --skill yt-structure -g -a codex

Open a new agent session and paste

Use the yt-structure skill to turn https://www.youtube.com/watch?v=eRsGyueVLvQ into a Markdown transcript and link me to the file.

Use your own video link next. If captions are unavailable, supply a VTT, SRT, or pasted transcript.
